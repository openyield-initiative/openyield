# v0.1 foundation development update

Status: implementation for review, not a released version. Date: 16 November 2026.

The feature branch adds an installable Python package, strict JSON scenario loader,
axis-aligned geometry, continuous translation monitors, a scripted encounter,
machine-readable outputs and a self-contained HTML replay. The website builds
locally with MkDocs. The introductory article remains a draft.

The default script begins with A already inside the bay. B passes; A translates
sideways and proceeds. This is a replayable demonstration, not a planner,
independent-driving baseline, negotiation method or comparative result.

Local verification: 27 tests passed, the default encounter completed in 18.25 s
over 73 accepted steps, and the strict docs build and clean wheel smoke test passed.
See [the verification record](../verification.md) for exact commands and visual checks. CI is
configured for Python 3.12 on Windows and Ubuntu; its actual run status must be
checked separately. Licensing, copyright ownership and later controller design
remain open. No site deployment, package publication or release tagging is included.
